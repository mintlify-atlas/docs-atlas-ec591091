NiceGUI gives you several complementary styling mechanisms — from high-level Quasar design tokens all the way down to raw CSS — so you can match any visual design without leaving Python. Because NiceGUI renders on top of Quasar and Vue 3, the full power of both ecosystems is available alongside NiceGUI's own helpers.

## Quasar Color Theming

Quasar drives most of NiceGUI's built-in component colors through a small set of **brand tokens** (primary, secondary, accent, etc.). You can override them globally for the whole application or on a per-page basis.

### Application-wide colors

Call `app.colors()` before `ui.run()` to set the default palette for every page:

```python
from nicegui import app, ui

app.colors(
    primary='#1976d2',
    secondary='#26a69a',
    accent='#9c27b0',
    dark='#1d1d1d',
    positive='#21ba45',
    negative='#c10015',
    info='#31ccec',
    warning='#f2c037',
)

@ui.page('/')
def index():
    ui.button('Primary button')  # uses the new primary color

ui.run()
```

### Per-page colors

`ui.colors()` overrides the global palette for the **current page only**:

```python
from nicegui import ui

@ui.page('/red-theme')
def red_page():
    ui.colors(primary='#c0392b', secondary='#e74c3c')
    ui.button('Red-themed button')
```

<Note>
  `ui.colors()` takes precedence over `app.colors()`. Use `app.colors()` for site-wide defaults and `ui.colors()` inside specific page functions when you need a different palette on a single route.
</Note>

### Custom brand colors

Pass arbitrary keyword arguments to register new color names that Quasar Tailwind utilities can reference. `ui.colors()` must be called **before** any element that uses the custom color token.

```python
from nicegui import ui

ui.colors(primary='#5898d4', brand_teal='#008080')
ui.button('Teal').classes('bg-brand-teal text-white')
```

## Dark Mode

`ui.dark_mode()` is a reactive element that lets you enable, disable, toggle, or track dark mode at runtime. A value of `None` means *auto* — it follows the operating system preference.

```python
from nicegui import ui

@ui.page('/')
def index():
    dark = ui.dark_mode()          # starts in light mode (value=False)

    with ui.row():
        ui.button('Light', on_click=dark.disable)
        ui.button('Dark',  on_click=dark.enable)
        ui.button('Auto',  on_click=dark.auto)
        ui.button('Toggle', on_click=dark.toggle)

    # Persist the choice across browser sessions
    ui.checkbox('Dark mode').bind_value(dark, 'value')
```

<Tip>
  To make the dark-mode preference stick across page reloads, bind the `dark` element's value to `app.storage.user` — a per-user persistent dict backed by the server.

  ```python
  dark = ui.dark_mode()
  dark.bind_value(app.storage.user, 'dark_mode')
  ```
</Tip>

## Per-element Styling

Every NiceGUI element inherits `.style()`, `.classes()`, and `.props()` from the `Element` base class, giving you three orthogonal styling axes.

### `.classes()` — Tailwind & Quasar utilities

Pass a whitespace-separated string of Tailwind CSS or Quasar utility classes. You can also remove, toggle, or replace classes:

```python
from nicegui import ui

# Add classes
ui.label('Hello').classes('text-2xl font-bold text-blue-600')

# Remove a class that was added by default
ui.button('Flat').classes(remove='shadow-md')

# Toggle a class
label = ui.label('Toggling')
ui.button('Toggle red', on_click=lambda: label.classes(toggle='text-red-500'))

# Replace all classes
ui.card().classes(replace='p-4 rounded-xl bg-gray-100')
```

### `.style()` — Inline CSS

Pass a semicolon-delimited CSS string directly to the element's `style` attribute:

```python
from nicegui import ui

ui.label('Custom font').style('font-family: "Comic Sans MS"; font-size: 1.5rem; color: purple')

ui.card().style('width: 320px; border: 2px dashed #5898d4; border-radius: 12px')
```

### `.props()` — Quasar component properties

Quasar components expose many props that control behaviour and appearance. Pass them as a whitespace-delimited string of `key` (boolean) or `key=value` pairs:

```python
from nicegui import ui

ui.button('Outlined').props('outline round color=secondary')
ui.input('Name').props('filled dense clearable')
ui.slider(min=0, max=100).props('label color=positive thumb-size=24px')
```

<Accordion title="Chaining all three methods">
  All three methods return `self`, so they can be chained fluently:

  ```python
  from nicegui import ui

  (
      ui.button('Save')
      .classes('q-mt-md')
      .style('min-width: 120px')
      .props('unelevated color=positive')
  )
  ```
</Accordion>

## CSS Selector Targeting with `ui.query()`

`ui.query(selector)` lets you apply classes, styles, and props to any element **already in the DOM** — including elements you did not create (like `body` or a third-party component's root). It matches the same CSS selector syntax used in `document.querySelector`.

```python
from nicegui import ui

# Style the page background
ui.query('body').classes('bg-gray-50').style('margin: 0')

# Override a Quasar internal element
ui.query('.q-drawer').style('background: #1a1a2e')

# Target a specific element by ID
ui.query('#my-card').classes('shadow-xl')
```

The `Query` object exposes the same `.classes()`, `.style()`, and `.props()` API as a regular element, including `add`, `remove`, `toggle`, and `replace` keyword arguments:

```python
from nicegui import ui

q = ui.query('body')
q.style(add='background-color: #f0f4f8')
q.classes(remove='dark')
```

## Injecting Custom CSS/JS

### `ui.add_head_html()`

Inject arbitrary HTML — `<style>`, `<link>`, `<script>`, or `<meta>` tags — into the `<head>` of the current page. Pass `shared=True` to add the snippet to **all** pages.

```python
from nicegui import ui

@ui.page('/')
def index():
    ui.add_head_html('''
        <link rel="preconnect" href="https://fonts.googleapis.com">
        <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap" rel="stylesheet">
        <style>
            body { font-family: "Inter", sans-serif; }
        </style>
    ''')
    ui.label('Custom font page')
```

### `ui.add_css()`

A convenience shorthand that wraps a CSS string (or a CSS file path) in a `<style>` tag and injects it via `add_head_html`. Accepts `shared=True`.

```python
from nicegui import ui

@ui.page('/')
def index():
    ui.add_css('''
        .hero-title {
            font-size: clamp(2rem, 5vw, 4rem);
            background: linear-gradient(135deg, #667eea, #764ba2);
            -webkit-background-clip: text;
            -webkit-text-fill-color: transparent;
        }
    ''')
    ui.label('Welcome').classes('hero-title')
```

You can also pass a `Path` to a `.css` file:

```python
from pathlib import Path
from nicegui import ui

ui.add_css(Path('assets/theme.css'), shared=True)
```

## Overriding Quasar Design Tokens

Quasar exposes CSS custom properties (`--q-primary`, etc.) that you can override to fine-tune the palette at a level below the Python API:

```python
from nicegui import ui

ui.add_css('''
    :root {
        --q-primary: #1976d2;
        --q-secondary: #26a69a;
        --q-font-size: 14px;
    }
''', shared=True)
```

<Tip>
  Use the [Quasar Theme Builder](https://quasar.dev/style/theme-builder) to generate a full `--q-*` palette, then paste it into `ui.add_css()`.
</Tip>

## Class-level Defaults

You can set default classes, styles, and props for an **entire element type** — every instance of that class shares the defaults, so you only define them once:

```python
from nicegui import ui

# Every ui.card will have this padding and rounded corner
ui.card.default_classes('p-6 rounded-2xl')
ui.card.default_style('box-shadow: 0 4px 24px rgba(0,0,0,.08)')

# Every ui.button becomes outlined by default
ui.button.default_props('outline')
```

<Warning>
  Call `default_classes()`, `default_style()`, and `default_props()` **before** instantiating elements of that type; they apply only to elements created afterwards.
</Warning>
