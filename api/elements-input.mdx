NiceGUI provides a rich set of form controls for collecting user input. All input elements inherit from the `ValueElement` mixin, which exposes `.value`, `bind_value()`, `bind_value_to()`, `bind_value_from()`, and `set_value()` as universal patterns. Most elements also accept an `on_change` callback whose argument is a `ValueChangeEventArguments` object with `.value`, `.previous_value`, `.sender`, and `.client` fields.

## `ui.button`

```python
ui.button(
    text: str = '',
    *,
    on_click: Handler[ClickEventArguments] | None = None,
    color: str | None = 'primary',
    icon: str | None = None,
)
```

A clickable push-button based on Quasar's `QBtn`.

<ParamField path="text" type="str" default="">
  Button label text.
</ParamField>

<ParamField path="on_click" type="Handler | None" default="None">
  Callback invoked when the button is clicked. Receives `ClickEventArguments`.
</ParamField>

<ParamField path="color" type="str | None" default="'primary'">
  Button color — Quasar, Tailwind, or CSS color. `None` removes all color styling.
</ParamField>

<ParamField path="icon" type="str | None" default="None">
  Optional Material Icon name to display on the button (snake_case, e.g. `'send'`).
</ParamField>

```python
from nicegui import ui

ui.button('Click me', on_click=lambda: ui.notify('Clicked!'))
ui.button('Icon button', icon='thumb_up', color='teal')

# await a click
async def handle():
    btn = ui.button('Wait for click')
    await btn.clicked()
    ui.notify('Done!')
```

**Extra methods:**

| Method | Description |
|--------|-------------|
| `.on_click(callback)` | Add another click handler after construction. |
| `await btn.clicked()` | Async: suspend until the button is clicked once. |

## `ui.input`

```python
ui.input(
    label: str | None = None,
    *,
    placeholder: str | None = None,
    value: str | None = '',
    password: bool = False,
    password_toggle_button: bool = False,
    prefix: str | None = None,
    suffix: str | None = None,
    on_change: Handler[ValueChangeEventArguments[str | None]] | None = None,
    autocomplete: list[str] | None = None,
    validation: ValidationFunction | ValidationDict | None = None,
)
```

A single-line text input based on Quasar's `QInput`.

<ParamField path="label" type="str | None" default="None">
  Floating label displayed above the field.
</ParamField>

<ParamField path="placeholder" type="str | None" default="None">
  Placeholder text shown when the field is empty.
</ParamField>

<ParamField path="value" type="str | None" default="''">
  Initial value.
</ParamField>

<ParamField path="password" type="bool" default="False">
  Mask the input text (password mode).
</ParamField>

<ParamField path="password_toggle_button" type="bool" default="False">
  Show a visibility toggle button next to a password field.
</ParamField>

<ParamField path="prefix" type="str | None" default="None">
  Static text prepended inside the input (e.g. `'$'`).
</ParamField>

<ParamField path="suffix" type="str | None" default="None">
  Static text appended inside the input (e.g. `'.com'`).
</ParamField>

<ParamField path="on_change" type="Handler | None" default="None">
  Called on every keystroke. For blur or Enter events, use `.on('blur', ...)` or `.on('keydown.enter', ...)`.
</ParamField>

<ParamField path="autocomplete" type="list[str] | None" default="None">
  Dropdown autocomplete suggestions.
</ParamField>

<ParamField path="validation" type="ValidationFunction | ValidationDict | None" default="None">
  Validation rules as a `{'Error message': lambda v: condition}` dict, or a callable returning `str | None`. Displayed as an error message below the input.
</ParamField>

```python
from nicegui import ui

ui.input(label='Username', placeholder='Enter username', autocomplete=['alice', 'bob'])
ui.input(label='Password', password=True, password_toggle_button=True)
ui.input(
    label='Email',
    validation={'Invalid email': lambda v: '@' in (v or '')},
)

# React only on blur
inp = ui.input(label='Search')
inp.on('blur', lambda e: ui.notify(f'Searching: {inp.value}'))
```

## `ui.number`

```python
ui.number(
    label: str | None = None,
    *,
    placeholder: str | None = None,
    value: float | None = None,
    min: float | None = None,
    max: float | None = None,
    precision: int | None = None,
    step: float | None = None,
    prefix: str | None = None,
    suffix: str | None = None,
    format: str | None = None,
    on_change: Handler[ValueChangeEventArguments[float | None]] | None = None,
    validation: ValidationFunction | ValidationDict | None = None,
)
```

A numeric input field with optional range clamping and decimal precision.

<ParamField path="label" type="str | None" default="None">
  Field label.
</ParamField>

<ParamField path="value" type="float | None" default="None">
  Initial numeric value.
</ParamField>

<ParamField path="min" type="float | None" default="None">
  Minimum allowed value.
</ParamField>

<ParamField path="max" type="float | None" default="None">
  Maximum allowed value.
</ParamField>

<ParamField path="precision" type="int | None" default="None">
  Number of decimal places. Negative values truncate before the decimal point.
</ParamField>

<ParamField path="step" type="float | None" default="None">
  Step size for the stepper arrow buttons.
</ParamField>

<ParamField path="prefix" type="str | None" default="None">
  Text prepended inside the input (e.g. `'$'`).
</ParamField>

<ParamField path="suffix" type="str | None" default="None">
  Text appended inside the input (e.g. `' kg'`).
</ParamField>

<ParamField path="format" type="str | None" default="None">
  `printf`-style format string, e.g. `'%.2f'`.
</ParamField>

```python
from nicegui import ui

ui.number(label='Price', prefix='$', min=0, step=0.01, format='%.2f')
ui.number(label='Age', min=0, max=120, precision=0)
```

**Runtime properties:**

```python
n = ui.number(label='Temperature', suffix='°C')
n.min = -50
n.max = 150
n.sanitize()  # clamp current value into range
```

## `ui.select`

```python
ui.select(
    options: list | dict,
    *,
    label: str | None = None,
    value: Any = None,
    on_change: Handler[ValueChangeEventArguments[Any]] | None = None,
    with_input: bool = False,
    new_value_mode: Literal['add', 'add-unique', 'toggle'] | None = None,
    multiple: bool = False,
    clearable: bool = False,
    validation: ValidationFunction | ValidationDict | None = None,
    key_generator: Callable | Iterator | None = None,
)
```

A dropdown select element based on Quasar's `QSelect`.

<ParamField path="options" type="list | dict" required>
  Options as a list (values equal to labels) or a dict mapping `{value: label}`.
</ParamField>

<ParamField path="label" type="str | None" default="None">
  Floating label displayed above the select.
</ParamField>

<ParamField path="value" type="Any" default="None">
  Initially selected value.
</ParamField>

<ParamField path="with_input" type="bool" default="False">
  Show a filter/search input inside the dropdown.
</ParamField>

<ParamField path="new_value_mode" type="str | None" default="None">
  Allow user-typed values: `'add'`, `'add-unique'`, or `'toggle'`. Implies `with_input=True`.
</ParamField>

<ParamField path="multiple" type="bool" default="False">
  Allow multi-selection (returns a list).
</ParamField>

<ParamField path="clearable" type="bool" default="False">
  Show a clear button to reset the selection.
</ParamField>

```python
from nicegui import ui

ui.select(['Apple', 'Banana', 'Cherry'], value='Apple', label='Fruit')
ui.select({'us': 'United States', 'gb': 'United Kingdom'}, label='Country')
ui.select(['Red', 'Green', 'Blue'], multiple=True, label='Colors')

# Dynamic options
s = ui.select([], label='Dynamic').props('clearable')
s.options = ['Option A', 'Option B', 'Option C']
s.update()
```

## `ui.upload`

```python
ui.upload(
    *,
    multiple: bool = False,
    max_file_size: int = 0,
    max_total_size: int = 0,
    max_files: int = 0,
    on_upload: Handler[UploadEventArguments] | None = None,
    on_rejected: Handler[UploadEventArguments] | None = None,
    label: str = '',
    auto_upload: bool = False,
)
```

A file upload widget based on Quasar's `QUploader`.

<ParamField path="multiple" type="bool" default="False">
  Allow selecting multiple files at once.
</ParamField>

<ParamField path="max_file_size" type="int" default="0">
  Maximum size per file in bytes. `0` means no limit.
</ParamField>

<ParamField path="max_files" type="int" default="0">
  Maximum number of queued files. `0` means no limit.
</ParamField>

<ParamField path="on_upload" type="Handler | None" default="None">
  Callback receiving `UploadEventArguments` with `.name`, `.content` (IO), `.type`, and `.size`.
</ParamField>

<ParamField path="on_rejected" type="Handler | None" default="None">
  Callback invoked when a file is rejected by size or type constraints.
</ParamField>

<ParamField path="label" type="str" default="">
  Button label text.
</ParamField>

<ParamField path="auto_upload" type="bool" default="False">
  Upload immediately after file selection.
</ParamField>

```python
from nicegui import ui

def handle_upload(e):
    content = e.content.read().decode()
    ui.notify(f'Received {e.name}: {len(content)} bytes')

ui.upload(on_upload=handle_upload, max_file_size=1_000_000).props('accept=".txt,.csv"')
```

<Note>
Use `.props('accept=".png,.jpg"')` to restrict accepted file types via the HTML `accept` attribute.
</Note>
