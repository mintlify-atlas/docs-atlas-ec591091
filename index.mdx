NiceGUI lets you build interactive, browser-based user interfaces using pure Python. Write UI logic once, and NiceGUI handles the web stack — a FastAPI/uvicorn backend communicates over WebSocket to a Vue 3/Quasar frontend, all without writing a single line of JavaScript or HTML.

## Why NiceGUI?

NiceGUI is designed for developers who want the power of a modern web UI without leaving Python. It's ideal for dashboards, robotics control panels, ML experiment tools, smart home interfaces, and rapid prototyping.

<CardGroup cols={3}>

  <Card title="Live Reload" icon="arrows-rotate">

## Get Started in 3 Steps

<Steps>
  <Step title="Install NiceGUI">
    ```bash
    pip install nicegui
    ```
  </Step>
  <Step title="Write your app">
    ```python main.py
    from nicegui import ui

    ui.label('Hello NiceGUI!')
    ui.button('Click me', on_click=lambda: ui.notify('Hello!'))

    ui.run()
    ```
  </Step>
  <Step title="Run it">
    ```bash
    python main.py
    ```
    Open [http://localhost:8080](http://localhost:8080) in your browser. The app hot-reloads whenever you save changes.
  </Step>
</Steps>
